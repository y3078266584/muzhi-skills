## 1. 选题方法

### 选题三问
动笔前必须全部回答"能"：
- **我经历过/感受过吗？** —— 没有第一手体验或真实感受的话题不写
- **我有感觉吗？** —— 没有情绪反应或思考冲动的话题不写
- **我能讲出一个故事或一个思考过程吗？** —— 没有叙事线或认知线的话题不写

### 选题交集模型
一个好选题 = 你的真实体验/感受 + 可迁移的个人思考 + 当下的表达冲动

光有体验，可能流于流水账。光有思考，可能空洞无物。光蹭热点，可能昙花一现。三者结合才能找到最精准的切入点。

### 选题来源
- **日常瞬间**：今天有什么让你停了一秒的事？哪怕很小。
- **朋友聊天**：跟朋友聊到什么的时候，你说了很多话？那个话题就是选题。
- **失败/困惑**：搞砸了什么？什么让你琢磨了很久？这些比成功案例更有价值。
- **情绪波动**：什么事让你开心、难过、生气、感动？追着情绪往深里挖。
- **学到的东西**：最近搞懂了什么？哪怕很小。把搞懂的过程写出来。
- **反复出现的念头**：有什么想法隔几天就冒出来一次？那就是你真正在意的东西。
- **阅读/观影触动**：看到了什么让你想说点什么？
- **生活决策**：做了什么选择？为什么？过程是怎样的？

## 2. 写作原型

沐挚的风格不是按"写什么"来分类，而是按"怎么写"来驱动。以下四种原型适用于任何题材，选择最贴合的那一种即可。

### 个人体验型
亲自经历了一件事，边经历边感受边记录。最能建立信任感。
- 写法核心：过程叙事 + 层层感受 + 每一步都带真实反应

### 感悟反思型
观察/经历 → 追问"为什么" → 知识/思考掉落 → 个人感悟。
- 写法核心：好奇心驱动 → 不急于给答案 → 展示思考过程比你给出的结论更重要

### 教学分享型
分享一个实用的方法/工具/思路，但必须用个人故事包裹。
- 写法核心：个人故事铺垫 → 自然引出要分享的东西 → 展示自己的使用/实践过程 → 坦诚不足

### 情感表达型
沐挚最私人的写作原型。情感是克制的，不煽情，用具体细节承载情绪。
- 写法核心：一个具体的场景或感受 → 展开内心的想法 → 认知转折（我原以为...后来发现...） → 温和收束
- 关键：激动时不喊，感动时不煽。

## 3. 节奏论

### 好的节奏像波浪
每次围绕主线偏出去一点点（让读者喘口气、长见识、看案例），再用一句话拉回来继续推进。

### 扣主线句要高频率出现
不需要长，一句就够，但频率要高。每2-3段就要回到核心感受或核心事件上。

### 最忌讳
突然偏离主线很远再硬拽回来。读者要花脑力"顺逻辑"，心流断掉。

### 优先级
真实体验/感受（底座）→ 个人思考（方向）→ 叙事/认知主线（绳子）→ 节奏起伏（牵引力）

## 4. 案例工作法

### 三类锚点
- **情感锚点**：最打动你的瞬间——情感共鸣。是什么让你鼻子一酸、心里一暖、突然笑了？
- **困惑锚点**：你一直没想通的问题——思考价值。把琢磨的过程写出来。
- **认知锚点**：让你"原来如此"的瞬间——知识价值。那个顿悟是怎么发生的？

### 微型故事包装法
即使是一篇观点文章，也要从一个微型故事开始：
1. 亮出一个具体的时刻或场景
2. 展示你当时的反应和感受
3. 引出你的思考和追问
4. 落回到你想表达的核心

### 准则
案例必须有独立的感受价值、思考价值和启发价值。如果自己都没感觉，坚决不写。
