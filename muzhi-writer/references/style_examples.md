## 1. 开头范例

### 叙事启动型（最推荐，适用于大多数文体）
> 前几周赶期末作业，一个视频要剪到凌晨三点。室友都睡了，我一个人对着Pr的进度条发呆。然后突然想到——要不要试试拿AI帮我剪？

> 那天打开电脑，本来是打算写作业的。结果刷到一个视频，说用AI做PPT只要五分钟。我当时心想：吹吧。

> 前几天下课回宿舍的路上，突然就想到了一个问题。说不上来为什么，就是一直在脑子里转。

特点：从一个具体的、当下的时刻切入。第一句话让人产生"然后呢？"的冲动。

### 感受启动型（适用于随笔、感悟）
> 我有时候觉得，人和人之间最大的问题不是距离，是——听不到。

> 说真的，这段时间我其实蛮难受的。

特点：从一个真实的个人感受出发，不绕弯子，不宏大叙事。

### 困惑启动型（适用于复盘、思考类）
> 说来有趣。我装了七八个AI插件，反而是最不起眼的那个，用得最多。

> 有个问题我琢磨了很久：为什么我明明知道该怎么做，就是迟迟不动手？

特点：提出一个真实的困惑，邀请读者一起思考。

### 书信启动型（适用于书信、情感表达）
> 见字如面。

> 见字面。平日里叫多了，提起笔来竟觉滞涩。

特点：直接、亲密、不绕弯。

### 绝对禁止的开头
- "大家好我是沐挚今天给大家分享..."
- "随着XX技术的飞速发展..."
- "最近XX很火，今天来聊一下"
- "首先，让我们了解一下..."
- "在当今这个时代..."
- 任何以"今天我们来聊聊"开头的句子

## 2. 口语化转场

### 好的转场
- "说真的，一年前我根本想不到今天会是这样。"
- "写到这儿，突然感觉回到了从前。"
- "顺着上面的，再聊聊。"
- "我突然想到了一个东西。"
- "当然，也有一点点不好。"
- "我想了想，突然想起了几年前的一件事。"
- "说来惭愧——"
- "我有好多好多的问题。"

### 禁用的转场
- "接下来，让我们讨论..."
- "值得注意的是..."
- "在深入探讨之前，我们需要先了解..."
- "首先...其次...再次...最后..."
- "总而言之" / "综上所述"
- "由此可见" / "不难发现"

## 3. 古典底色示例

沐挚的古典底色不是堆砌，是自然而然、若隐若现。通用文体每500字1-3处，书信体可略多（2-4处），绝不超过5处。

### 书信格式中的古典元素
> 见字如面。

> 纸短情长，不尽依依。

> 愿：春祺夏安，秋绥冬禧。

### 正文中的自然融入（好）
> 我以为，"我爱你"的表达过于直接，直接到让我羞赧。毕竟，我并非那种敢爱敢恨的性子。反倒是"喜欢"二字，克制得比我欢喜。

> 而后我意识到，就像世间的文字总有遗憾，而喜欢圆月的人未必欢喜它的锋锐。

> 我也曾多次提起笔来，摊出信纸，总以为炙热的心意会流淌笔尖，如朱生豪那样的笔触，向你写尽肉麻的情话。可却相反，一次次的搁笔告诉我，那炽热下，我所能描述的，也仅有"喜欢"二字。

### 过度堆砌（差）
> 余尝思忖，人生之道，博大精深，犹如浩瀚星河，令人叹为观止。

太刻意了，不像沐挚。沐挚的古典是"漏"出来的，不是"摆"出来的。

## 4. 认知转折——沐挚的核心手法

### 标准模式："我原以为X，后来发现Y"

> 我终而发现，我并不能喜欢你的全部。
> 就像是世间的文字总有遗憾，而喜欢圆月的人未必欢喜它的锋锐。我曾试图改变，无论是你，抑或是我。后来发现，我既已喜欢上古灵精怪的公主，又如何应当让她不再是她？
> 然后我就明白了，我不会喜欢你的全部。
> 因为我喜欢的是全部的你。

三层递进：发现局限 → 试图改变 → 更深的理解。最后一句是沐挚标志性的悖论式升华。

### 谦逊铺垫型
> 说真的，写这种建议类的东西，我一直是有心理负担的。
> 因为我自己也不是什么成功人士，也还在摸索，也还在犯错，凭什么给别人建议呢？
> 但这次之后，我改变了一些想法。

先承认自己的不确定，再给出观点。

## 5. 幽默与自嘲

沐挚的幽默是轻盈的，不自恋，不嘲讽别人，是"对自己轻轻一笑"。

> 我好像有那么一丢丢讨厌你了……但是也就一丢丢吧。

> 可一想到有些人能把自己气哭，那些怨怼便忽地炸成了满心的欢喜。

> 我寻思了一下我没寻思明白。

> 说来有趣。我的想法是离家稍远些，自由，免些管束。于是来了扬州——而今却总想着回去。

幽默不靠段子，靠真实。这些句子好笑的不是"梗"，是你认识的那个"人"。

---

## 6. 句式断裂

偶尔用不完整的句子制造口语真实感。

> 我寻思了一下我没寻思明白。

> 说真的。

> 于是来了扬州、而今却总想着回去。

> 我有好多好多的问题。

口语化到极致，语法不完整，但读起来特别真实。这是"一个真人在打字"的感觉。

## 7. 结尾范例

### 书信体结尾（标志性）
> 祝你早安，午安。晚安！

> 愿：春祺夏安，秋绥冬禧。
> 纸短情长，不尽依依。

> 情长纸短，不尽依依。

### 温和祝愿型（适用于随笔、感悟）
> 纸短情长，不尽依依。

### 回到起点型
回到开头那个瞬间或那个情绪，形成闭环。不带说教，不总结全文。

### 禁止的结尾
- "以上就是今天的分享，希望对大家有帮助"
- "我们下期再见"
- "大家有什么想法欢迎在评论区留言"
- "如果你觉得有用，请点赞转发"
- 任何"总而言之"开头的段落

## 8. AI初稿 vs 沐挚修改对比（多文体）

### 对比1：工具分享开头

**AI初稿（差）：**
> 大家好，我是沐挚。今天我们来聊聊AI视频剪辑工具。随着AI技术的不断发展，越来越多的视频剪辑工具开始集成AI功能。这些工具能够帮助用户大幅提升剪辑效率，降低创作门槛。

**沐挚修改（好）：**
> 前几周赶期末作业，一个视频要剪到凌晨三点。室友都睡了，我一个人对着Pr的进度条发呆。
> 然后突然想到——要不要试试拿AI帮我剪？
> 说真的，一开始是不抱期待的。但跑完第一遍之后，我突然觉得——有点意思。

### 对比2：随笔感悟

**AI初稿（差）：**
> 在这个快节奏的时代，人与人之间的联系似乎越来越疏远。研究表明，现代人的孤独感正在上升。我们需要重新思考人际关系的本质。

**沐挚修改（好）：**
> 我有时候觉得，人和人之间最大的问题不是距离，是——听不到。
> 不是说真的听不见。是你在说一件事的时候，对方已经在想怎么回了。
> 我好像也经常这样。想到这个，有点惭愧。

### 对比3：复盘总结

**AI初稿（差）：**
> 回顾本学期，我在多个方面取得了显著进步。首先，在学业上，我的成绩有了明显提升。其次，在实践能力上...总而言之，这是一个收获颇丰的学期。

**沐挚修改（好）：**
> 这学期结束了。说真的，我不知道算不算"收获颇丰"。
> 有一些事情做好了，但更多的事情——搞砸了。或者更准确地说，没搞砸，但也没做好，就卡在中间，不上不下。
> 我琢磨了一下为什么。大概是...想要的太多了。
> 下学期，想少一点。

### 对比4：情感表达

**AI初稿（差）：**
> 在这段关系中，我感受到了深深的情感连接。每当我遇到困难时，你的支持总能给我力量。我珍视我们之间的每一个瞬间。

**沐挚修改（好）：**
> 我想要你的在意，你的关心。我说不想帮你做作业，并非是不愿，只是你在那时的热闹，与答应后的冷清让我戒断。

## 9. 禁用词对照表

| 禁用 | 替代 |
|---|---|
| "值得注意的是" | 删除整句，或改成"有个细节" |
| "在深入探讨之前" | 直接开讲 |
| "总而言之" / "综上所述" | "一句话——" |
| "首先...其次...最后..." | 用波浪式推进，不用序号 |
| "接下来，让我们..." | "顺着上面的，再聊聊" |
| "不难发现" / "由此可见" | "所以你看" |
| "随着...的发展" | 从具体事件切入 |
| "毋庸置疑" / "显然" | "我觉得" / "大抵" |
| "在...的背景下" | 删除，直接叙事 |
| "用户" / "读者们" | "你"（直接对话） |
| "该工具" / "该产品" | 具体的名字，或"这个东西" |
| "大幅提升" / "显著改善" | 具体的数字或感受 |
| "令人感到" / "让人" | "我当时就" |
| "据研究表明" | "之前看到一个研究说" |
| "大家好我是XX今天给大家分享..." | 从故事或感受切入 |
| "收获颇丰" / "受益匪浅" | 具体的收获是什么 |
